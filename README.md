# 📩 SMS Spam Classification using Naive Bayes

## 📌 Overview

This project presents a Natural Language Processing (NLP) approach for detecting spam messages using the SMS Spam Collection dataset.

The project includes data exploration, text preprocessing, feature extraction with CountVectorizer, model training using Naive Bayes, and performance evaluation.

---

## 🎯 Objectives

- Explore the SMS Spam dataset
- Preprocess text data
- Convert text into numerical features
- Train a Naive Bayes classifier
- Evaluate model performance

---

## 📂 Dataset

This project uses the **SMS Spam Collection** dataset.

The dataset contains over 5,500 SMS messages labeled as:

- Ham (legitimate)
- Spam

---

## 🤖 Model

- Multinomial Naive Bayes

---
